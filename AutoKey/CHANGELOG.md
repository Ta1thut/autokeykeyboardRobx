# Changelog

## 1.0.1
- แก้: ปุ่ม F8 ถือค้างแล้วสลับเริ่ม/หยุดรัว (เพิ่ม MOD_NOREPEAT)
- แก้: UI เล็กเกินไปบนจอ High-DPI (ปรับขนาดตาม DPI)
- แก้: ปิดโปรแกรมขณะกำลังกดค้าง ปุ่มอาจค้าง (รอ worker thread ปล่อยปุ่มก่อนปิด)
- แก้: ช่วงเวลา "ทุก X นาที" เลื่อนสะสม (นับจากเริ่มรอบก่อนแทนจบรอบก่อน)
- แก้: memory leak ของข้อความสถานะเมื่อปิดหน้าต่าง, int overflow ของค่าที่กรอก
- แก้: `F1X` ถูกอ่านเป็น `F1`
- build: ไม่พึ่ง `_wtoi`/`std::to_wstring`, เพิ่ม `win_common.h`, แก้ manifest ซ้ำใน MSVC

## 1.0.0
- เวอร์ชันแรก: กดปุ่มอัตโนมัติตามลำดับ ตั้งเวลาทำซ้ำเป็นนาที/วินาที
- รองรับปุ่มผสม (`CTRL+C`), `WAIT:ms`, คลิกเมาส์ (`LMB`/`RMB`)
- สุ่มเวลา ±20%, หน่วงก่อนเริ่ม, จำกัดจำนวนรอบ, ปุ่มลัด F8
