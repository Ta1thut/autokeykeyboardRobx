# AutoKey

โปรแกรมกดปุ่มคีย์บอร์ด/เมาส์อัตโนมัติสำหรับ Windows ฟีลมาโคร ตั้งได้ว่ากดปุ่มอะไร เว้นจังหวะเท่าไร และทำซ้ำทุกกี่นาที
เขียนด้วย C++17 + Win32 API ล้วน ไม่พึ่งไลบรารีภายนอก ได้ไฟล์ `.exe` ไฟล์เดียว

## ฟีเจอร์

- เลือกปุ่มที่จะกดเอง เช่น `W,A,S,D`
- ปุ่มผสมกดพร้อมกัน เช่น `CTRL+C`, `W+A`
- แทรกหน่วงเวลาเอง `WAIT:500` และตั้งเวลากดค้าง/เว้นช่วงต่อปุ่ม (ms)
- ตั้งเวลาทำซ้ำเป็นนาที + วินาที, จำกัดจำนวนรอบ หรือทำไม่จำกัด
- สุ่มจังหวะ ±20% ให้เหมือนคนกดจริง
- นับถอยหลังก่อนเริ่ม ให้สลับไปหน้าต่างเกมทัน
- ปุ่มลัด **F8** เริ่ม/หยุด (ใช้ได้แม้โฟกัสอยู่ในเกม)
- ปุ่ม "ทดสอบ 1 รอบ"

## ปุ่มที่ใช้ได้

| กลุ่ม | ตัวอย่าง |
|---|---|
| ตัวอักษร/ตัวเลข | `A`–`Z`, `0`–`9` |
| ฟังก์ชัน | `F1`–`F24` |
| พิเศษ | `SPACE` `ENTER` `TAB` `ESC` `SHIFT` `CTRL` `ALT` `BACKSPACE` `DELETE` `INSERT` `HOME` `END` `PGUP` `PGDN` |
| ลูกศร | `UP` `DOWN` `LEFT` `RIGHT` |
| เมาส์ | `LMB` (คลิกซ้าย) `RMB` (คลิกขวา) |
| หน่วงเวลา | `WAIT:500` |

## วิธี Build

ต้องใช้ Windows และคอมไพเลอร์ C++17 อย่างใดอย่างหนึ่ง

**แบบง่ายสุด (MinGW-w64):**
```bat
scripts\build_mingw.bat
```
ได้ไฟล์ `build\AutoKey.exe`

**แบบ CMake:**
```bat
scripts\build_cmake.bat          :: Visual Studio
scripts\build_cmake.bat mingw    :: MinGW Makefiles
```

## หมายเหตุ

- "ทำซ้ำทุก X นาที" นับจากเวลาที่ **เริ่ม** รอบก่อนหน้า เวลาจึงไม่เลื่อนสะสม
- ปุ่มถูกส่งแบบ scan code (ตำแหน่งปุ่มจริงบนคีย์บอร์ด) ถ้าใช้กับโปรแกรมพิมพ์ข้อความ ตัวอักษรที่ได้จะตามภาษาของคีย์บอร์ดที่เลือกอยู่
- F8 เป็นปุ่มลัดทั่วเครื่อง ขณะเปิด AutoKey โปรแกรมอื่นจะใช้ F8 ไม่ได้
- ค่าตัวเลขในช่องกรอกถูกจำกัดช่วงอัตโนมัติ (เช่น WAIT สูงสุด 1 ชั่วโมง) กันค่าผิดปกติ
- ถ้าเกมรันด้วยสิทธิ์ Administrator ให้คลิกขวา AutoKey แล้ว **Run as administrator** ด้วย
- เกมออนไลน์บางเกมห้ามใช้มาโครหรือมี anti-cheat ที่ตรวจจับ ควรอ่านกฎของเกมก่อนใช้งาน
